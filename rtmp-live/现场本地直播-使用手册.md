# DJI Air 3S 现场本地直播（不推流，本机观看）

> 目标：无人机画面通过 RC2 的 RTMP 推到**你自己的电脑**上，直接在 `DJILive.exe` 窗口里看。
> 全程**不往抖音/视频号/公网推**，也**不需要 ffmpeg**。
> **v2.0 起已内置 OpenCV 播放器**：画面直接在 exe 窗口里显示，不再开浏览器。

---

## 一、原理（一句话）

```
Air 3S ──OcuSync──► RC2 (DJI Fly 原生 RTMP)
                      │  (同一个 Wi-Fi / 局域网)
                      ▼
              你的电脑：MediaMTX 收流 (:1935)
                      │  自动开出 RTSP(:8554) 等本地播放
                      ▼
        DJILive.exe 内置播放器 (OpenCV 拉 RTSP, 窗口内直接看)
        + 每帧调用 analyze(frame) AI 钩子 (默认空操作)
```

MediaMTX 一个 exe 同时干两件事：**收** RC2 推来的 RTMP，**放**给你本机看。
**最省事的办法是用 `dist/DJILive.exe`**——它把 MediaMTX 服务端、启动器界面、内置播放器**全部打包进一个 exe**，双击就跑，不用装任何东西、不用碰命令行。

---

## 二、只要两步（双击即用）

### 推荐：`dist/DJILive.exe`（全打包，开箱即用）
1. 双击 **`DJILive.exe`**（在 `dist` 文件夹里）→ 弹出窗口自动显示你电脑的**局域网 IP**。
2. RC2 上开播（见下方地址），然后点窗口里的 **「② 启动服务器」** → **「③ 开始预览」**，画面**直接显示在 exe 窗口内**（OpenCV 拉 RTSP 流渲染，不开浏览器）。
   - 关窗口即停服务。

### 备选：分开的脚本（如不想用 exe）
- 双击 **`1-START-server.bat`** → 列出本机 IP，保持黑窗口开着。
- RC2 填地址开播（见下）→ 双击 **`2-WATCH.bat`** 打开浏览器看。

### 遥控器上填地址开播（两种方式都一样）
在 RC2 上：**DJI Fly → 直播 → 选「RTMP」/「自定义」**，地址填：
```
rtmp://你电脑的IP:1935/live/drone1
```
例如电脑 IP 是 `192.168.10.20`，就填 `rtmp://192.168.10.20:1935/live/drone1`
点**开始直播**。

### 看画面
- **exe 版（推荐）**：点窗口里 **「③ 开始预览」**，画面直接显示在 exe 窗口内。
- 备选（仍可用）：浏览器打开 WebRTC `http://localhost:8889/live/drone1`，或 VLC 看 `rtsp://localhost:8554/live/drone1`。
- 黑屏就确认：① 服务器已启动；② RC2 已真正开播；③ 稍等几秒让 RTSP 建链。

---

## 三、两个必须满足的前提（否则开不了播）

1. **RC2 要插麦克风**：DJI Fly ≥ V1.16.0 硬性要求，不插麦点「开始」会卡住。随便一个 USB-C 麦/DJI Mic 接收端/耳麦转接都行。
2. **RC2 和电脑在同一局域网**：最省事是**电脑开个热点，让 RC2 连电脑的热点**；或两者连同一个路由器 Wi-Fi。
   - ⚠️ 直播走的是 **RC2 的无线网**，**不是那根 USB 线**。USB 线跟这条直播路径无关。

---

## 四、观看方式

| 方式 | 地址/入口 | 延迟 | 说明 |
|------|------|------|------|
| **exe 内置播放器**（推荐） | 点「③ 开始预览」 | ~0.5–1 秒 | 画面直接在 exe 窗口里，无需浏览器 |
| 浏览器 WebRTC | `http://localhost:8889/live/drone1` | ~0.3–1 秒 | 浏览器直接开，最跟手 |
| 浏览器 HLS | `http://localhost:8888/live/drone1` | ~2–5 秒 | 更稳 |
| VLC RTSP | `rtsp://localhost:8554/live/drone1` | ~0.5 秒 | VLC「打开网络串流」 |

> 在**别的设备**（同网的手机/平板）上看，把 `localhost` 换成电脑的 `192.168.x.x` 即可（浏览器/VLC 方式；exe 内置播放器只播本机流）。

## 四·五、AI 识别口子（预留扩展）

启动器在**每一帧显示前**都会调用一个 **`analyze(frame)`** 钩子：默认空操作（原样显示）。
你只要在同目录放一个 `analyzer.py`，就能接入目标检测 / 识别，**无需重打包 exe**。

用法：
1. 把 `dist/analyzer_template.py` 复制并重命名为 **`analyzer.py`**，放到 `DJILive.exe` 同一个文件夹。
2. 编辑里面的 `analyze(frame)` 函数：
   - 入参 `frame`：`numpy.ndarray`，shape `(H,W,3)`，**颜色空间 BGR**（OpenCV 默认）
   - 返回：同形状的 `numpy.ndarray`（BGR），保持不变即原样显示
   - 例如接入 YOLO 画框——模板里已给出注释好的示例代码
3. 重启 exe → 点「③ 开始预览」，识别结果（框/文字）直接叠加在画面里。

启动器会显示当前加载的 AI 模块名（未加载时显示「无」），方便确认是否生效。

> 提示：AI 推理尽量轻量，避免每帧阻塞导致掉帧；重模型建议降采样或降频。

## 五、排错

### ⚠️ 第一优先：Windows 防火墙（90% 的「RTMP 连不上」都是它干的）

电脑上的 `mediamtx.exe` 虽然监听了 `:1935`，但 **Windows 防火墙默认会拦掉 RC2 从局域网发来的入站连接**，导致 RC2 一直「连接中 / 超时 / 失败」。

**一键修复**：右键文件夹里的 **`fix-firewall.bat`** → 「以管理员身份运行」→ 放行 1935/8554/8888/8889 端口。
**自查**：双击 **`diag-rtmp.bat`**，看第 [3] 项是否显示「已放行 ✅」。

> 注：用 `dist\DJILive.exe` 也一样——它内置同一个 mediamtx，防火墙照样要放行。

- **点开始直播卡住/失败** → 90% 是防火墙；其次：没插麦克风；或 IP 填错 / RC2 与电脑不同网。
- **exe 窗口黑屏/一直"连接中"** → ① 服务器没启动；② 无人机还没真正开播；③ 等几秒让 RTSP 建链；④ 确认 RC2 与电脑同网。
- **RTMP 日志显示已连接、但画面一直黑** → 多半是 RC2 推的是 **H.265/HEVC**，OpenCV 内置播放器和浏览器 WebRTC 解不了。救法：用 **VLC** 打开 `rtsp://localhost:8554/live/drone1`（VLC 能解 H.265）；或尽量在 RC2 端把直播编码设成 H.264。
- **RC2 连不上电脑热点** → 确认电脑热点开着、RC2 Wi-Fi 选对；有的电脑热点是 5GHz，个别设备只认 2.4GHz，可把热点设成 2.4GHz。
- **看得到但很卡** → RC2 直播码率调低（3 Mbps），或改用 HLS。RC2 直播最高 720p 是硬件限制，正常现象；飞机本体仍在录 4K，两者互不影响。
- **换个流名** → 把地址里的 `drone1` 换成任意英文名即可（如 `live/cam2`），观看地址同步改。
- **AI 模块没生效** → 确认 `analyzer.py` 与 `DJILive.exe` 在同一文件夹；`analyze` 函数名、签名正确；状态栏是否显示模块名。

## 六、文件清单

| 文件 | 作用 |
|------|------|
| **`dist/DJILive.exe`** | **（推荐）全打包启动器**：内置 mediamtx 服务端 + 图形界面 + OpenCV 内置播放器，双击即用，无需安装 |
| `dist/analyzer_template.py` | AI 分析钩子模板：复制改名 `analyzer.py` 放 exe 同目录即可接入识别 |
| `mediamtx.exe` | 收流 + 本地播放服务（核心；已被打包进 DJILive.exe） |
| `mediamtx.yml` | 配置（默认即可，无需改） |
| `1-START-server.bat` | 备选：双击启动服务，并显示要填的 RTMP 地址 |
| `2-WATCH.bat` | 备选：双击打开浏览器本地观看 |
| `fix-firewall.bat` | **RTMP 连不上时首选**：右键「以管理员身份运行」放行 1935/8554/8888/8889 端口 |
| `diag-rtmp.bat` | 一键自检：显示本机 IP、端口监听状态、防火墙是否放行 |
| `现场本地直播-使用手册.md` | 本文件 |
